Start with the raw data: which folder holds the dumps, which series to process, and which detector took them. Raw data from different detectors (or different folders) are separate sources: add one with + Add a source; the steps then run on all of them. Tip: in an empty box, press Tab to fill in the grey suggestion.

Build the processing as boxes. Add a step and drag it where you like; click a box to set its parameters. To make a step read a filter's result, drag from the filter's right-hand dot onto that step (double-click a line to undo). The number on a box is the order the steps run in: a step comes after the one it reads, and otherwise the one further left runs first. The green boxes are the quantities that end up in the output files.
